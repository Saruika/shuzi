# 1.5 (1): album presentation maintenance beta

User authorization: publish the first 1.5 beta to both existing internal and external TestFlight groups. The user explicitly clarified that 2.0 is a separate major concept version; this release fixes the existing app.

Baseline: 1b4d3b500fa7435978b0cb7cdb1d4f7be3faca5e, whose application source is the distributed 1.4.0 (13), 550a43289918365c9ab144e4b3c1fcba7aafdcc7. Only album presentation, its regression checks, and version numbers change.

- Album names and categories appear below covers using theme-aware text colors.
- Album first photos use the full width and their actual aspect ratio, avoiding the fixed-height portrait side gutters while preserving the full photo.
- Detail headings/descriptions sit below the image.
- Existing portfolio header, navigation, gallery behavior, favorites storage, home pager, account flows and screenshot protection are retained. No 2.0 resume/filter/immersive-gallery feature migration; no server, online-photo, account or formal App Store change.

Validation and Apple distribution state will be documented separately. TestFlight build availability is not proof of installation on the user's device.
