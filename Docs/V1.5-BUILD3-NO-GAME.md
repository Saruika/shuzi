## 范围与发布边界

- 移除关于页游戏入口、WebKit 游戏宿主、排行榜界面与客户端成绩接口。
- 删除游戏资源、规则、题库和专用测试夹具，不再保留旧客户端在线游戏兼容接口。
  原始代码仍可通过 Git 历史追溯，不重写仓库历史。
- 当前客户端隐私清单与本地商店文案不再宣称提供游戏或采集新游戏成绩；
  政策仍如实说明历史数据及删除途径。
- 保留相册、影视、消息箱、注册审批、管理员功能及截图保护，不扩大公开选片范围。
- 用户随后明确扩大范围：移除服务端游戏接口、排行榜表及游戏专用状态，清理旧游戏包，
  发布新的内部和外部 TestFlight。数据库清理须精确限定游戏数据，先备份再执行。
- 官网、App 内政策、隐私清单和测试文案与实际停服/清理结果一并更新，
  不把“新包移除”错误表述为“从未收集过”。此次独立退役备份验收后精确清理；
  不擅自删除包含其他业务的整站历史备份，不允许通过备份恢复游戏业务。
- 本次不重新提交正式 App Store 审核；上传、分组和外部审核状态须分别核实。
