# 1.5 (5) — iPhone Duo / iOS 27.1 SDK

日期：2026-10-19。分支：`feat/iphone-duo-layout`，基于 `codex/v1.5-network-audit-fixes`（`fd25935`）。

## 变更

- **工具链**：Xcode 27.1（`27A9275`）、iPhoneOS 27.1 SDK（`24A94232`）。27.1 SDK 是 iPhone Duo 全屏布局和纵向系统栏的启用条件；27.0 构建在展开屏上只会获得过渡布局。`Scripts/archive-testflight.py` 及其测试中锁定的工具链同步更新，最低系统仍为 iOS 17。
- **平板尺寸布局不再只看设备类型**：iPhone Duo 展开后 idiom 仍是 `.phone`，但窗口为 regular 宽高。新增 `AppLayoutCanvas.isTabletSized`，iPad 行为不变，另把 regular/regular 的 iPhone 窗口视为平板尺寸：
  - 关于页：满足原有宽度（≥700pt）等条件时使用固定人物图双栏布局；
  - 相册查看器：使用原 iPad 的左右留白。
  普通 iPhone 竖屏（compact 宽）与大屏 iPhone 横屏（compact 高）保持手机布局。
- 构建号 4 → 5。

未改变：启动时的系统通知授权请求（产品要求，用于推送）、公开浏览与审批门禁、截图保护、iPadOS 27 导航栏搜索修复、首页图片 fill/fit 规则（本就按宽高比判断）。
