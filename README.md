# Hi，梳子 iOS

“Hi，梳子”是易姝的原生 iPhone / iPad 艺人作品 App，用于展示摄影作品、演员 Showreel、影视履历与合作信息。客户端使用 SwiftUI 实现，通过稳定的版本化内容清单同步，不是 WebView 封装。当前兼容清单由 WordPress 发布，下一代后台将按 [`ARCHITECTURE_V2.md`](ARCHITECTURE_V2.md) 分阶段迁移。

> 当前版本：`1.3.27 (39)` · 最低系统：iOS 17 · Bundle ID：`cn.com.shuzijun.yishu`

## 产品功能

- **首页**：人物主视觉轮播、身份表达和作品入口；可按需通过 Apple WeatherKit 显示当地天气。
- **作品**：按造型和拍摄主题分类的原生相册，支持搜索、收藏、最近浏览和下拉刷新。
- **影视**：内嵌 Showreel 与公开影视履历，支持静音和暂停，不弹出系统全屏播放器。
- **收藏**：收藏和最近浏览按粉丝账号分开保存，退出或换号时不会向另一账号暴露记录。
- **关于**：艺人简介、社交平台、合作邀约和管理员入口。
- **注册审批**：保留身份码与密码登录，并新增原生“通过 Apple 登录”。Apple 首次验证后仍必须由本人填写抖音 ID、确认隐私政策并提交申请，管理员批准后才开放 App 主内容。
- **一次性邀请**：管理员可批量生成最多 5 个 24 小时临时账号；本人首次登录必须填写真实抖音 ID、同意隐私政策并更换密码，完成前无法访问作品内容。
- **账号安全**：密码账号可自助改密，所有账号都可查看已登录设备并撤销其他会话；Apple 账号不在 App 内设置密码。忘记密码时由管理员为密码账号生成只显示一次的短时恢复凭据。
- **内容工作台**：管理员可直接在手机内替换开屏、首页轮播、关于页人物图、相册照片、Showreel 与影视海报，并调整轮播和相册顺序。
- **用户权限**：管理员可按昵称、抖音 ID 或身份码查找粉丝，远程分配白名单内的 App 权限或暂停账号。
- **Apple 平台体验**：界面使用系统安全区、语义字体、44pt 主触控区和原生导航材质，支持 iPhone/iPad 横竖屏、Dynamic Type、VoiceOver、减少动态效果与减少透明度。

## 作品访问规则

| 身份 | 可见内容 | 获取方式 |
| --- | --- | --- |
| 未登录用户 | 仅注册、身份码登录、Apple 登录、隐私政策和管理员入口 | 无内容清单权限 |
| Apple 已验证但未绑定抖音 ID | 仅资料填写、退出和账号删除 | 10 分钟 Apple onboarding 会话 |
| 已提交但待审批/被拒用户 | 仅申请状态、刷新、会话管理和账号删除 | 已绑定安装记录的粉丝会话 |
| 已批准粉丝 | 首页、作品、影视、收藏、关于及获授权限 | 已批准粉丝会话 + App 专用内容清单 |
| 内容管理员 | 注册审批、用户权限与全部内容编辑 | WordPress Application Password |

TestFlight 测试阶段已暂停付费订阅；只有管理员批准的粉丝账号才能进入主内容。服务端会继续根据“完整相册”和“影视内容”权限裁剪同一会话的清单：没有完整相册权限时每册最多返回 3 张，没有影视权限时不返回 Showreel 或影视地址。官网作品页、附件页及通用 WordPress 媒体列表继续关闭。

账号、审批和内容清单请求使用 `https://shuzijun.com.cn/wp-json/...` 直达上海权威节点，避免 CDN 在 401/403 响应后切换到尚未实时同步的备用数据库。官网和媒体仍由 CDN 提供上海主源、新加坡备源的连续性；状态型账号接口在主节点不可用时失败关闭。

## 技术结构

```text
iOS App (SwiftUI / AuthenticationServices / WeatherKit / AVKit)
        │
        ├─ 身份码登录───────────────┐
        ├─ Apple 验证──绑定抖音 ID──┼─ 管理员审批──已批准粉丝会话
        ├─ 已批准访问───────────────┘        └─ 版本化 App Content Manifest
        └─ 内容与审批── WordPress Application Password + 最小权限角色
```

项目中不包含云 API 密钥、Apple 私钥、WordPress 管理员密码或签名证书。

## 本地运行

需要 Xcode 17 或兼容 iOS 17 SDK 的新版本 Xcode。

1. 克隆仓库：`git clone git@github.com:Saruika/shuzi.git`
2. 打开 `Yishu.xcodeproj`。
3. 选择 iPhone / iPad 模拟器或已加入开发团队的真机。
4. 运行 `Yishu` Scheme。

真机测试 Apple 登录前，还必须为 App ID `cn.com.shuzijun.yishu` 开启 Sign in with Apple 与 WeatherKit，并重新生成包含两项能力的开发/发布描述文件。服务端需安装锁定版本的 Composer 依赖，在 Web 根目录外配置 Sign in with Apple 私钥及 `YISHU_APPLE_TEAM_ID`、`YISHU_APPLE_KEY_ID`、`YISHU_APPLE_PRIVATE_KEY_PATH`，并允许访问 Apple JWKS、令牌与撤销端点。私钥及常量不得提交到仓库。

命令行验证：

```bash
xcodebuild -project Yishu.xcodeproj \
  -scheme Yishu \
  -configuration Debug \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max' \
  build
```

## 安全与隐私

- 管理员访问码不做持久化，只在当次短时内存会话中使用；每次进入管理员入口都要重新登录，退到后台或 5 分钟后自动锁定。
- 粉丝密码只保存标准哈希；原会话令牌仅在 ThisDeviceOnly Keychain，服务器只保存令牌和随机安装标识的 SHA-256 哈希。
- 密码恢复临时密码只在创建结果中显示一次，服务器只保存密码哈希和带过期时间的恢复状态；恢复或主动改密会撤销原有会话。
- 账号页只展示安装记录码、登录时间和到期时间等会话元数据，不显示原会话令牌；用户可撤销其他设备会话。
- App 主内容要求粉丝注册并获得管理员批准；注册前显示数据用途并获取明示确认，申请页和账号页均提供无需联系客服的完整账号删除。
- Apple 登录采用服务端生成、绑定安装记录且一次性消费的 nonce/state challenge；客户端不信任或上传 Apple user ID，也不持久化身份令牌、授权码、nonce 或 state。
- 冷启动展示受保护缓存前会先查询 Apple 凭据状态；明确撤销、找不到、转移或未知状态会失败关闭。系统查询暂时失败时保留仍有效的服务器会话，并进行有界退避复查。
- 永久删除前，密码账号要求近期密码验证，Apple 账号要求原生 Apple 重新授权；删除会撤销 Apple 授权、清除服务器账号资料、恢复状态和全部会话，并清除本机该账号的收藏与最近浏览。
- 完整图片 URL 仅在运行时内存中使用，磁盘目录缓存每册只保留 3 张离线预览，不后台预取整册照片。
- 录屏、投屏或 App 失去活动状态时会显示黑色保护遮罩。
- 位置仅在用户主动启用天气时请求；定位管理器采用约三公里精度，不持久化位置，也不在后台持续定位。天气由 Apple WeatherKit 提供；首页只显示地点与天气，不放置商标或来源入口；Apple Weather 商标、数据来源和许可链接集中放在“关于”页，元数据请求失败时使用 Apple 官方来源页兜底。
- 仓库忽略 `.env`、Apple 私钥、证书、描述文件和本地构建产物。
- App 明示照片与影像均已取得合法展示授权；相关版权和肖像权归各自权利人所有，未经许可不得下载、复制、传播、改编或商业使用。

截图保护是 iOS 系统能力限制下的尽力防护，无法阻止另一台设备拍摄屏幕；已公开过的 WordPress 原图在迁移到私有对象存储前，也不能承诺绝对无法下载。完整安全边界和上线前 P0 清单见 [`SECURITY.md`](SECURITY.md)。
