Hi，梳子 App 隐私政策

生效日期：2026 年 8 月 31 日

本政策说明“Hi，梳子”App 如何处理注册申请、管理员审批、账号访问、天气和必要安全数据。查看 App 的首页、作品、影视、收藏和关于内容前，需要注册账号并获得管理员批准。

我们处理的数据

  • 粉丝账号：昵称、必填的抖音 ID、服务器生成的 UUID 和粉丝身份码。
  • Apple 登录：使用 Apple 登录时，我们处理 Apple 提供的假名唯一账号标识（仅以服务器 HMAC 摘要绑定）、一次性 challenge 的哈希和加密的 refresh token。identity token 和 authorization code 仅用于当次验证，不会持久化。用户尚未同意本政策和补填抖音 ID 前，仅保存完成安全登录与自主删除所必需的最小身份绑定、有效期和会话安全数据。
  • 管理员邀请：在用户本人完成首次设置前，仅保存随机临时身份、邀请有效期和审批记录；临时密码只在创建时展示一次，服务器仅保存标准密码哈希。
  • 账号安全：密码哈希、随机安装记录的哈希、会话令牌哈希、不可用于登录的会话 ID、安装记录码、登录/到期时间和权限状态。App 不读取硬件 UDID，也不使用 IDFA。
  • 密码恢复：管理员创建短时恢复凭据时，服务器保存密码哈希，以及恢复记录的生成标识、创建/过期时间、创建者、首次领取时间、领取安装记录哈希和恢复会话 ID。临时密码只在创建时显示一次，不持久化为可读明文。
  • 天气：仅在用户主动开启时使用前台粗略位置，由 Apple WeatherKit 提供天气；App 不持久保存坐标。
  • 安全与诊断：服务器为防止滥用和排查故障可处理 IP 地址、请求时间、错误状态和有限运行日志。

使用目的

上述数据只用于创建和验证账号、使用 Apple 作为登录身份处理方验证同一账号、密码恢复与修改、让用户查看和撤销其他登录设备、发出一次性账号邀请、由本人完成账号设置、提交和处理访问申请、由管理员核对抖音 ID、批准或拒绝 App 访问、远程分配权限、提供用户主动请求的天气、保护服务安全及排查故障。我们不使用这些数据进行跨 App 跟踪、定向广告或出售给数据经纪商。

共享与处理者

账号数据保存在用于运行本服务的云服务器上。管理员创建邀请或密码恢复时只能看到一次临时凭据，无法再次查询，也无法查看用户本人设置的新密码。管理员日常仅能查看核验和权限分配必需的昵称、抖音 ID、身份码、账号来源和权限，无法查看 Apple 账号唯一标识或授权凭据。Apple 是 Apple ID 登录身份验证的处理方；登录或删号时，授权码与 token 会通过加密连接发送给 Apple 验证或撤销。天气请求由 Apple WeatherKit 处理。我们要求所有为本服务处理用户数据的服务提供方遵守与本政策相同或同等的保护要求。

保存、撤回同意与删除

  • 账号和权限数据保存至用户在 App 内主动删除账号，或者服务依法终止。会话最长 30 天。
  • Apple identity token 和 authorization code 仅用于即时验证，不持久保存。加密的 Apple refresh token 仅保留到账号删除或 Apple 授权终止，用于向 Apple 撤销授权。若 Apple 撤销服务短暂不可用，本服务仍会立即删除用户数据，只将无法回链用户或抖音 ID 的加密 token 置入有限重试队列，成功或最长 7 天后销毁。
  • 用户完成新 Apple 授权删号，或服务收到 Apple 签名的授权终止/账号删除通知后，服务会最长 30 天保留无法回链昵称、抖音 ID 或内容权限的 Apple 标识 HMAC 摘要、删除/事件时间和随机世代，仅用于阻止此前已验证的旧授权并发重建账号。Apple 在该时间之后签发的新授权可重新发起申请，但该安全边界仍保留至 30 天届满，以拦截迟到的旧请求。
  • Apple 签名通知在确认接收前，会先把完成删除所必需的事件类型、时间和 Apple 标识 HMAC 摘要写入受保护的待处理记录，并在锁忙或暂时失败时后台重试至处理成功。成功后会立即移除该摘要和事件明细，只保留最长 30 天、无法回链用户的已处理防重放标记。
  • 密码恢复凭据只在 15 分钟内有效；完成恢复、重新生成或删除账号时会移除恢复记录。未完成的过期状态可随账号保留至下次生成或删号，仅用于拒绝过期凭据，不能获得内容访问。
  • 未完成设置的邀请在 24 小时后失效并删除临时记录；完成设置时会立即撤销临时凭据和旧会话。
  • 用户可选择不提交注册申请，但此时不能进入受限内容页面；用户也可不开启天气、退出账号，或通过删除账号撤回后续账号数据处理同意。
  • 在登录后的账号页，或尚未获批的申请状态页点击“永久删除账号与个人资料”，密码账号通过近期密码验证，Apple 账号通过同一 Apple ID 的全新原生授权后，即可由用户自己发起完整删除，无需联系客服或等待审批。尚未补填抖音 ID 的 Apple 待完成申请也可删除。
  • 待审批、被拒绝或被暂停均不影响用户主动删除账号。
  • 删除会立即移除账号、昵称、抖音 ID、身份码、权限、恢复记录、安装记录和会话，并清除本机该账号的收藏与最近浏览。隔离备份中的残留数据随备份周期删除，且不用于日常业务。依法必须保留的记录除外。

安全

App 使用 HTTPS、Keychain、有效期会话、令牌哈希、设备安装绑定、限流和最小权限管理来减少未授权访问风险。
