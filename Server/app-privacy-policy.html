Hi，梳子 App 隐私政策

生效日期：2026 年 9 月 5 日

本政策说明“Hi，梳子”App 如何处理注册申请、管理员审批、账号访问、消息通知、天气和必要安全数据。查看 App 的首页、作品、影视、收藏和关于内容前，需要注册账号并获得管理员批准。

我们处理的数据

  • 粉丝账号：昵称、抖音 ID、服务器生成的 UUID 和粉丝身份码。抖音 ID 是注册、Apple 登录资料补全和邀请账号首次设置的必填项，仅用于管理员核验账号身份，不向其他粉丝公开。
  • Apple 登录：使用 Apple 登录时，我们处理 Apple 提供的假名唯一账号标识（仅以服务器 HMAC 摘要绑定）、一次性 challenge 的哈希和加密的 refresh token。identity token 和 authorization code 仅用于当次验证，不会持久化。用户尚未同意本政策并完成账号申请前，仅保存完成安全登录与自主删除所必需的最小身份绑定、有效期和会话安全数据。
  • 管理员邀请：在用户本人完成首次设置前，仅保存随机临时身份、邀请有效期和审批记录；临时密码只在创建时展示一次，服务器仅保存标准密码哈希。
  • 账号安全：密码哈希、随机安装记录的哈希、会话令牌哈希、不可用于登录的会话 ID、安装记录码、登录/到期时间和权限状态。App 不读取硬件 UDID，也不使用 IDFA。
  • 消息通知：首次打开 App 时会请求系统通知授权。用户选择允许后，App 会在首次完成粉丝账号登录及必填资料后开启该账号的消息通知，并将 Apple 提供的不透明推送设备令牌与该账号及随机安装记录关联；未登录时不会上传设备令牌。用户也可稍后在账号页主动开启。拒绝通知不影响注册和浏览，原来已主动关闭的通知偏好会保留，切换账号不会继承前一个账号的开启状态。服务器加密保存令牌并使用 HMAC 索引，管理员不能查看令牌原文。该数据只用于向用户的账号发送审批状态、合作进度和作品动态等通知。
  • 云端消息箱：保存管理员向用户发送的标题、正文、发送时间、收件关系和已读时间。消息箱只用于接收与查看，不提供粉丝之间发送、回复或私聊。用户无需允许系统通知也能在登录并完成必填资料后查看本人消息；敏感消息的系统提醒只展示通用提示，原文经账号验证后在 App 内读取。
  • 密码恢复：管理员创建短时恢复凭据时，服务器保存密码哈希，以及恢复记录的生成标识、创建/过期时间、创建者、首次领取时间、领取安装记录哈希和恢复会话 ID。临时密码只在创建时显示一次，不持久化为可读明文。
  • 管理员内容上传：仅内容管理员登录后，可主动通过系统照片选择器或文件选择器选取照片、视频和封面并上传发布。这些媒体与管理员账号及发布记录关联，用于向已获批用户提供 App 内容；普通粉丝功能不读取或上传设备照片。
  • 合作邀约：用户可主动填写联系人姓名、联系方式、组织、项目类型、城市、意向日期、预算和项目说明。合作服务未启用服务器提交时，填写内容仅保留在当前页面；只有用户主动点击“发送到工作邮箱”并在系统邮件应用中确认后，才由邮件服务交给合作邮箱。若未来明确启用服务器提交，只有用户主动点击提交后，上述字段以及粉丝身份码和安装记录码才会通过 HTTPS 交给服务器，供获得合作邀约权限的管理员处理，并由邮件发件队列发送至配置的合作邮箱。
  • 天气：仅在用户主动开启时使用前台粗略位置，由 Apple WeatherKit 提供天气；App 不持久保存坐标。
  • 安全与诊断：服务器基础设施可在安全日志中处理 IP 地址，应用限流使用哈希化网络指纹。请求时间、错误状态和有限运行日志可能与已验证账号或会话关联，仅用于防止滥用、保障服务和排查故障，不用于跟踪或广告。

使用目的

上述数据只用于创建和验证账号、使用 Apple 作为登录身份处理方验证同一账号、密码恢复与修改、让用户查看和撤销其他登录设备、发出一次性账号邀请、由本人完成账号设置、提交和处理访问申请、批准或拒绝 App 访问、远程分配权限、向开启通知的指定账号发送与 App 功能相关的消息、让内容管理员上传和发布授权影像、回复用户主动发送的合作邀约并安排合作、提供用户主动请求的天气、保护服务安全及排查故障。抖音 ID 仅用于管理员辅助核验；未填写时不能完成新账号申请或获得内容访问。我们不使用这些数据进行跨 App 跟踪、定向广告或出售给数据经纪商。

共享与处理者

账号数据和管理员主动发布的影像保存在用于运行本服务的云服务器上；App 根据已验证账号的状态和权限决定界面中可见的内容。管理员创建邀请或密码恢复时只能看到一次临时凭据，无法再次查询，也无法查看用户本人设置的新密码。管理员日常仅能查看核验和权限分配必需的昵称、身份码、账号来源、权限和抖音 ID，无法查看 Apple 账号唯一标识、授权凭据或推送设备令牌。Apple 是 Apple ID 登录身份验证与通知交付的处理方；登录或删号时，授权码与 token 会通过加密连接发送给 Apple 验证或撤销，通知由 Apple Push Notification service（APNs）交付。天气请求由 Apple WeatherKit 处理。我们要求所有为本服务处理用户数据的服务提供方遵守与本政策相同或同等的保护要求。

保存、撤回同意与删除

  • 账号和权限数据保存至用户在 App 内主动删除账号，或者服务依法终止。会话最长 30 天。
  • Apple identity token 和 authorization code 仅用于即时验证，不持久保存。加密的 Apple refresh token 仅保留到账号删除或 Apple 授权终止，用于向 Apple 撤销授权。若 Apple 撤销服务短暂不可用，本服务仍会立即删除用户数据，只将无法回链用户或抖音 ID 的加密 token 置入有限重试队列，成功或最长 7 天后销毁。
  • 用户完成新 Apple 授权删号，或服务收到 Apple 签名的授权终止/账号删除通知后，服务会最长 30 天保留无法回链昵称、抖音 ID 或内容权限的 Apple 标识 HMAC 摘要、删除/事件时间和随机世代，仅用于阻止此前已验证的旧授权并发重建账号。Apple 在该时间之后签发的新授权可重新发起申请，但该安全边界仍保留至 30 天届满，以拦截迟到的旧请求。
  • Apple 签名通知在确认接收前，会先把完成删除所必需的事件类型、时间和 Apple 标识 HMAC 摘要写入受保护的待处理记录，并在锁忙或暂时失败时后台重试至处理成功。成功后会立即移除该摘要和事件明细，只保留最长 30 天、无法回链用户的已处理防重放标记。
  • 密码恢复凭据只在 15 分钟内有效；完成恢复、重新生成或删除账号时会移除恢复记录。未完成的过期状态可随账号保留至下次生成或删号，仅用于拒绝过期凭据，不能获得内容访问。
  • 未完成设置的邀请在 24 小时后失效并删除临时记录；完成设置时会立即撤销临时凭据和旧会话。
  • 管理员上传的照片、视频和封面保存至内容管理员替换或删除，并按服务器备份周期清理隔离副本。
  • 推送设备绑定最长 90 天未刷新会自动过期，App 在持续使用时会至少每 24 小时重新确认一次绑定。用户在 App 内关闭消息通知、退出、删除或切换账号时，App 会立即请求 iOS 撤销本机远程通知注册；服务器连接可用时，还会在正常会话与安装记录匹配后，全局清除该安装可能残留的旧账号设备绑定。为防止迟到或乱序的网络请求覆盖最新选择，服务器在当前会话期限内保留安装记录哈希、当前会话所有权、单调绑定操作序号和期望状态，不含设备令牌或通知内容，最长随登录会话在 30 天内到期。撤销相关会话、删除账号或 APNs 报告令牌无效时，服务器也会删除对应绑定。通知在创建时即固定最长 24 小时的投递期限，超期不再发送；推送内容与投递状态最长保留 30 天后清理，用于防重复发送、有界重试和故障排查。
  • 云端消息原文、收件关系和已读状态自创建起最长保留 30 天；已读时间只用于消息状态同步，不用于广告、画像或追踪。删除账号时移除该账号的收件关系和已读状态；当一条消息已无任何收件用户时清除其正文。App 不把消息正文写入本地持久存储，退出或切换账号时清空内存中的消息。关闭系统通知仅停止设备提醒，不会删除消息箱内容。
  • 合作邀约信息仅用于回复和安排合作。邮件模式下由合作邮箱保留；若服务器提交功能未来启用，后台邀约、发件队列和关联审计会保留至事项处理完毕，但在用户删除账号时会一并删除与该账号关联的在线记录。已经交给邮件服务的邮箱副本无法由 App 自动撤回，用户可通过隐私邮箱请求查阅、更正或删除；备份剩余副本随服务器备份周期清理，依法必须保留的记录除外。
  • 抖音 ID 是完成账号申请和访问内容的必需资料；如用户不愿提供，可不完成注册或邀请设置，并可删除已创建的申请或账号。存量空抖音 ID 账号补全前不能访问影像，但仍可登录、退出和主动删号；密码账号可在账号页验证当前密码后补全，Apple 账号需重新使用同一 Apple ID 验证。消息通知是可选功能；用户可在账号页随时关闭并解绑设备，也可在 iOS 系统设置中更改通知权限。用户还可不开启天气、退出账号，或通过删除账号撤回后续账号数据处理同意。
  • 在登录后的账号页，或尚未获批的申请状态页点击“永久删除账号与个人资料”，密码账号通过近期密码验证，Apple 账号通过同一 Apple ID 的全新原生授权后，即可由用户自己发起完整删除，无需联系客服或等待审批。尚未完成 Apple 账号申请的用户也可删除。
  • 待审批、被拒绝或被暂停均不影响用户主动删除账号。
  • 删除会立即移除账号、昵称、已填写的抖音 ID、身份码、权限、恢复记录、与账号关联的安装记录和设备令牌、会话，以及服务器上与该账号关联的合作邀约、待发邮件记录和关联审计，并清除本机该账号的收藏与最近浏览。为阻止删号前的迟到请求重新绑定，仅保留已与账号断开关联、无法回链昵称或抖音 ID 的安装哈希、操作序号和“已解绑”状态，最长保留至原会话到期且不超过 30 天，之后自动删除。隔离备份中的残留数据随备份周期删除，且不用于日常业务。已经交给外部邮件服务的副本需通过隐私邮箱申请删除；依法必须保留的记录除外。

安全

App 使用 HTTPS、Keychain、有效期会话、令牌哈希、设备安装绑定、限流和最小权限管理来减少未授权访问风险。
