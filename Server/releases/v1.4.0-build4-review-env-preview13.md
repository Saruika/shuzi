# v1.4.0-build4-review-env-preview13

日期：2026-09-07。App 退出登录与环境切换的慢网络清理。

## 原因与修复

环境切换会等待旧账号退出。原来的推送解绑和会话注销复用常规账号 transport，每个请求
可等待 30 秒无响应/45 秒资源超时，两项顺序执行；本地访问虽然早已清除，切换界面仍可能长时间等待。

- 清理改用独立 ephemeral URLSession，每项请求和整个请求资源的超时均为 3 秒，
  不等待网络恢复。两项仍顺序尝试，解绑失败不阻止旧会话注销。
- 每次退出只使用已冻结的旧 token、安装记录和解绑 generation；清理完成后关闭自己的 transport，
  不取消后来登录账号使用的常规 transport，也不让旧响应更新本地登录状态。
- 登录、注册、账号删除及其他常规请求保留原 30/45 秒策略，默认连接恢复等待策略不变。
- 没有磁盘缓存、Cookie 或 URL 凭据存储，继续拒绝 HTTP 重定向。没有更改页面风格、审批、
  抖音必填、免费访问、管理员权限语义或生产服务器配置。

## 限制与剩余

短超时只能约束清理等待，不能保证离线时服务器必定已收到注销。退出仍先同步清除本地访问，
后台解绑/注销为尽力完成；账号删除流程没有使用该短超时，不会将本地退出当作服务器删号成功。
