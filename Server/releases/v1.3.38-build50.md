# Build 50：相册放大与拖动性能修正

App `1.3.38 (50)`，2026-09-05。

## 范围

包含 [v1.3.37-build49.1](v1.3.37-build49.1.md) 的相册修正：用 UIKit 手势与 UIScrollView 处理缩放和拖动，避免手势期间反复向 SwiftUI 提交图片内容；高清图就绪后替换预览，减少重复图片合成。保留页面外观、完整构图、1–4 倍缩放、双击恢复、翻页、关闭及图片保护，不新增磁盘图片缓存。本次不部署服务器或合并未提交的运维工作。

## 验证依据

- 独立 iPhone 构建 168 项单元测试通过，包含原生连续 100 次位移不重设图片内容、旋转重置缩放及图片身份边界回归。
- iPhone 17 Pro Max 与 iPad Pro 13-inch (M5) 各四组 UI 配置通过：三轮双指放大、双向拖动、双击恢复、翻页、关闭，未关闭图片保护。
- 测试证据及中间失败原因见源码补丁记录；跨机型复用 thinned 资源的两项图标检查失败已由独立 iPhone 构建验证，不将含失败的整份结果包标为成功。
- 模拟器操作回归不等同于真机帧率测量；尚无 Instruments 或真机前后掉帧对比，需用新版 TestFlight 验收实际流畅度。

已获用户授权上传 TestFlight 并停用全部旧包。当前准备隔离源码归档、发行包检查与上传，尚未确认新包可测试；仅在新构建 `VALID`、内部 `IN_BETA_TESTING` 后才设置旧构建为过期。TestFlight 不提供直接删除已上传构建的操作，不删除源码、测试员或测试组，不提交正式 App Store 或外部 Beta 审核。
