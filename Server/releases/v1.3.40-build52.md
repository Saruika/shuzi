# Build 52：开屏文案以后台最新发布内容为准

App `1.3.40 (52)`，2026-09-05。已上传并确认 TestFlight 内部可测试。

## 已确认原因

Build 51 只修复了后台预览画布和新增草稿默认文字，没有修正启动数据顺序：RootView 从内置/缓存内容冻结开屏快照之后才请求已授权的最新清单。后台编辑器读取最新清单，两处因此可能不同。只读检查上海生产配置确认，三张现有古风海报的副标题为“镜头之内，自有叙事。”；客户端内置默认值则是“很高兴，在这里遇见你。”。不能把修改新草稿默认值当作已有生产内容的迁移。

## 修正边界

- 开屏选择移到最新已授权内容刷新之后，使用后台发布的原始眉题、标题和副标题，保留自定义文字与每张海报的独立投放计划。
- 首次配置读取设置 4 秒截止并取消慢请求；失败时跳过海报，不展示缓存/内置旧文字，也不在后台重试成功后突然补弹。普通内容同步继续。
- 已发布空数组、缺少海报字段、停用或到期均不会复活内置海报。只有 Debug 视觉测试允许明确使用示例海报。
- 退出、换号、被替代的请求和清理后的旧缓存读取不再恢复旧内容。配置元数据采用串行读取/写入/删除，避免异步写入乱序；仍不保存图片数据。
- 不修改实际海报画布、字体、相册、视频播放器或生产后台文字，不部署服务器插件，不用测试文案污染生产环境。

模拟器使用隔离测试数据，没有登录生产管理员或发布测试文案，因此不冒充用户真机实际管理发布的端到端验收。
