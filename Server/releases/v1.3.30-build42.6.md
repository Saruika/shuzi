# Hi，梳子 1.3.30 / Build 42.6 noexec 预检兼容修复

Build 42.6 取代 Build 42.5 中的签名同步发布器候选。新加坡节点的首次
`--dry-run` 在任何备份、服务或站点变更前失败关闭，原因是生产环境将
`/run` 挂载为 `noexec`，而发布器尝试直接执行暂存的 webroot 预检脚本。

本版修复：

- 发布器仍按 SHA-256、owner、mode、inode 及禁止 symlink 合同验证暂存预检脚本。
- 验证通过后改由固定的 `/bin/bash` 读取该脚本，不需要放宽 `/run` 的 `noexec`。
- authority 与 standby 两个预检分支使用同一执行合同。
- 合同测试明确禁止恢复从 `/run` 直接 exec 的写法。

Build 42.5 的 standby dry-run 只产生了一次 `Permission denied` 预检结果；当时
`/run/shuzijun-sync-release` 操作锁和生产同步服务仍未创建，未发生生产状态变更。

```text
SYNC_DEPLOYER=06b33ffa84e57ac44f27596041a53e2bbe32ed60a118b0400c8eae3575b0dc74
SYNC_DEPLOYER_TEST=cf94b11e349a99f6e01dd2b679abd8ffe8147f77c85c89d9822a78dbd52b67c7
SECURITY_CHECK=ac11fb16823dbce7f94a888e26d5faebaf84ff392df3f7c5fdeadf18d49bbee9
```

本修复不修改 DNS、CDN 主源、故障转移或 generation，不包含 SSH/签名私钥、
云 API 凭据、密码、手机号或会话令牌。
