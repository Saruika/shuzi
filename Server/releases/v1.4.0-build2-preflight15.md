## 修改范围

- 图片的辅助功能缩放值即时读取 UIScrollView.zoomScale，避免保存动画/手势完成前的旧值。
- 单测覆盖六次连续缩放读值，并验证读取/缩放不会重建 hosted artwork 子树。
- 不调整图片裁切、页面布局、播放器、翻页方式或截图保护；不改变服务端与商店版本号。
- 原生手势替换实验在普通和受保护容器的八种测试运行均失败，已撤回。
  对照用例、临时日志与诊断启动标志不进入本提交。
