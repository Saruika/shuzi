# v1.4.0-build4-review-env-preview8

2026-09-07 · App 环境切换生命周期与系统通知路由，未上传 TestFlight。

- App 通过一组不可变环境服务装配账号、后台管理、内容、收藏、最近浏览与推送。
  默认仍为正式环境，不改变页面内容、主题、播放器或既有存储键。
- 切换时先移除旧根页面和导航/弹窗/草稿，停用推送、锁定管理会话、退出账号、清理内容和
  内存图片，再创建新服务；重复切换串行化，开始清理后取消也不会重新挂载退役服务。
- 旧账号传输仅允许已冻结凭据的退出/解绑清理；旧内容服务拒绝迟到清单或缓存恢复。
  退役的推送协调器不能再次申请、绑定、接收消息或因迟到回调撤销新环境的注册。
- 系统推送回调统一经过当前环境路由。无环境字段的旧消息只属于正式环境；演示消息需明确
  `serviceEnvironment: review`，不匹配/未知值被拒绝。冷启动只暂存规范消息 UUID，
  不用推送内容自动切换环境，也不绕过消息详情的账号授权。
- 添加仅 DEBUG 的切换测试控件，用于操作真实服务装配及根页面；不是 Release 演示入口。
