## 修改

- 管理员普通 JSON 请求使用独立的 30 秒请求 / 45 秒资源时限；照片上传保留
  120 / 180 秒。两个传输都使用 ephemeral 会话，不配置 URLCache、持久凭据或磁盘图片缓存。
  切换环境时同时取消旧会话，不改变授权、审批、管理员绑定或跨环境隔离规则。
- 不因权限写入超时而自动重试或显示成功；网络故障不等同于撤销登录凭据。
  这里验证的是配置和异常处理，不承诺网络中断时服务端尚未执行，也未测量真实网络等待上限。
- 关于页边界测试改测现有 DEBUG 画布，而不是在图片失败时被转交给重试按钮的图片标识。
  正常分支使用内存中的真实解码测试图片，失败分支明确要求重试按钮出现；保留职业说明完整性、
  底部余量、状态栏、双栏及可点击导航断言。测试照片只存在于 DEBUG 内存中。
  未修改生产 AboutView、页面视觉、照片、字体或播放器。
