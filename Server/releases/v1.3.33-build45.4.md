# Hi，梳子 1.3.33 / Build 45.4 推送 Worker 降权顺序热修复

该记录用于 Git 标签 `v1.3.33-build45.4`。iOS 与 App Content API 版本不变。生产同构
systemd 沙箱复现确认：`setpriv --bounding-set=-all` 会先移除 UID 切换所需 capability，
随后 `setresuid` 返回 `EPERM`，因此 Build 45.3 仍在 immutable 属性检查前失败。上海
定时器已再次暂停，没有通知被发送。

本热修移除两处显式 bounding-set 修改。systemd 进程本身仍只保留 `CAP_SETUID` 和
`CAP_SETGID`；切换到 `www-data` 时内核会清除 permitted/effective capability，命令同时
清空补充组、inheritable/ambient capability 并设置 `no-new-privs`，因此子进程不能重新
获得权限。相同沙箱参数下的 `www-data` immutable 检查已在生产节点以临时诊断 unit
验证成功。
