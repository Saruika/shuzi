## 复现和修复

正式 Build 6 中，“演示环境 · 独立账号与资料”覆盖了登录页导航、作品搜索和二级页面标题的一部分。模拟器修复前断言实际失败：提示底边 y=73.33，导航按钮顶边 y=51，重叠约 22 点。

原因是 AppAppearanceModifier 在受保护 hosting 层级外使用 safeAreaInset，原生导航/搜索仍使用旧的窗口 inset。审核环境现在为原有提示保留实际布局行；正式环境不增加提示或占位。没有修改品牌文案、相册内容或正式截图保护。

新增离线布局夹具仅在 DEBUG、审核环境和显式测试参数全部满足时启用；不复制生产相册，图片由既有合成加载器提供。Release 产物检查禁止包含该夹具入口。

另修正 Release 检查中的 strings | grep -q：在 pipefail 下提前退出可能造成 SIGPIPE，将已命中误判为未命中。改为完整消费输出；大输出合成验证能够正确发现标记。
