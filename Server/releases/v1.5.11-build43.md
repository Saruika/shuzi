# App Content API 1.5.11 / Build 43 发布记录

该记录随 Git 标签 `v1.3.31-build43` 保存。本版将新注册、Apple 资料
提交、一次性邀请设置和存量空 ID 补全统一为“抖音 ID 必填”，
并保留旧合法同意记录的登录连续性。空 ID 存量账号在自助补全前
可登录、退出和删除账号，但不能读取受保护影像。

合作邀约 Phase 1 继续保持硬熔断关闭；代码候选同时补齐持久化
收件箱、邮件发件箱和删号联动清除，并在持有粉丝锁且开启事务后
从数据库重新校验会话、用户状态、抖音 ID、同意版本和权限，
阻断审批或撤权与提交之间的竞态窗口。邮件能力只有在生产明确配置
收件地址和已验证发信通道后才会被能力接口公布。

本服务端版本不得在 App 1.3.31 Build 43 具备分发条件前部署，
以免仍提交旧同意版本的 Build 42 新申请被拒绝。生产发布仍必须
按备节点 `standby` 先、上海节点 `authority` 后执行 dry-run/apply，
且不得在未完成的整站同步事务中替换生产插件。
