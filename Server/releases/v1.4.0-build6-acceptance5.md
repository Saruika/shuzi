## 已修复

- 合作页面原来固定使用正式 API 和正式 Keychain 凭据，不跟随当前环境。现改由当前
  FanAccountStore 授权，绑定用户、会话世代和服务环境；不再另读 Keychain。请求前校验
  当前会话及目标 origin；返回后再次核对，切换/退出/续签后的迟到结果不再进入界面。
  环境或账号变更时清空邀约字段、同意状态及旧提示。原页面样式和正式截图保护不变。
- 服务端原来仅写邮件任务，缺少管理员消息任务。候选现在将 admin_notice 和 work_mail
  与邀约同事务保存；管理员任务先入队，各自重试。每个获批且有当前合作权限的管理员
  使用独立稳定幂等键写入云消息，再复用已有 APNs 队列；部分失败/崩溃后重试不重复建消息。
  私有系统 actor 不能由 REST 请求指定；事务内重新核验收件权限。正文只提示有新邀约，
  不复制联系人、项目或预算。无合格管理员、存储故障或人数超限均不假报完成。
- 邮件不可用不阻止已排队的管理员任务，管理员任务失败也不发送额外邮件；两条链都与
  删号使用同一提交人锁，避免已删除的邀约继续发出。成功/重试/终止审计区分渠道。
- 本地隐私清单补齐与发件人关联的客户支持；App 内与官网政策来源明确邮箱/电话/微信、
  客服关联及仅主动复制。新增结构化披露清单和自动一致性检查，不把线上已保存视为已核验。
