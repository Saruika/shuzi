# 用户绑定管理员：App 会话接入

日期：2026-09-06（Asia/Shanghai）

候选标签：`v1.4.0-build2-preflight17`。基线：`a1c37accdb85720fe1f371c23fb340223c8fa178`。
本轮不改变 App Store 版本号、构建号或服务端插件摘要；服务端运行代码沿用 preflight16 / 1.5.13.6。

## 实现

- 获批且已绑定管理员身份的用户，可在既有管理登录页选择“使用当前账号进入管理”。
  仍需服务端管理会话核验成功；资料中的 `administratorBound` 仅用于显示入口，不等于授权。
- 当前用户的 Bearer 与安装标识由账号服务按请求填写，管理服务不另存用户令牌或密码。
  请求前、响应后都核对用户 ID 与登录会话代次，同一用户重新登录也不能复用旧管理会话。
- 退出、撤权资料刷新、换号、审批失效、未完成抖音/Apple/密码设置和会话过期时拒绝管理。
  账号状态变化后清除管理 UI 状态；迟到响应不会解锁或覆盖新账号状态。
- 保留旧网站管理员的独立 Basic 登录。绑定用户不能借用该身份例外绕过资料或审批。
  首页、相册、播放器、开屏样式与免费政策未改动。
- 现有媒体接口的 REST 前置鉴权可识别绑定用户，WordPress 原生媒体创建权限使用
  `upload_files`。本轮用真实控制器验证了该权限连接，并验证撤权后阻止进入控制器；
  不新增整站编辑权限，也不凭推测增加另一个上传接口。

## 已执行验证

- 最终代码在 iPhone 17 Pro Max / iOS 26.5 模拟器上：200 项单元测试通过，0 失败。
  新增 10 项管理会话测试，覆盖正常登录、服务端拒绝/伪成功、审批及设置门禁、
  换号、同账号会话更替、退出后迟到响应、可见状态锁定、旧 Basic 登录兼容性。
  所有网络测试使用注入式响应，不用生产凭据。
- 新建模拟器先运行首次系统通知授权测试，通过后才启动单元测试宿主。
- iPhone 管理员页面可关闭、未审批不能进入内容：2 项界面测试通过。
- iPad Pro 13 英寸（M5）/ iOS 26.5：同样先验证首次通知授权，再运行全部 200 项单元测试
  和上述 2 项界面测试，均通过、0 失败。两个设备的测试都使用本轮最终 Swift 代码。
  这不是全功能 UI 回归，也不能替代实际绑定账号和上传文件的联调。
- 真实隔离 WordPress 7.1 / MySQL 8.0.46：345 项断言通过，包含新增 5 项媒体权限衔接断言。
