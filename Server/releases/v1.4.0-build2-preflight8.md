# 合作私密信息加密组件：隔离验证

版本记录：`v1.4.0-build2-preflight8`，2026-09-06。这是合作数据隐私改造的基础组件，**尚未接入 REST 写入/读取、Outbox 或生产发布包**，不能据此宣称当前合作数据已经加密或自动邮件已经可用。生产合作开关继续关闭；App、数据库和服务器配置未修改。

## 范围

新增 `Server/collaboration-private-payload.php`，采用 PHP/Sodium 的 XChaCha20-Poly1305 认证加密。每次加密使用新的随机 24 字节 nonce；版本、密钥标识、实际粉丝用户 ID 与请求 UUID 共同绑定认证上下文，防止不同用户/请求间交换密文后仍可读取。使用调用方提供的独立 32 字节合作密钥，不读取或复用 Apple 密钥。

输入限于约定的八个私密字段，检查类型、UTF-8 JSON 和大小上限。密文封装、版本和编码严格校验；错误密钥、字段篡改、换用户/换请求、损坏或旧明文数据均返回失败，没有明文降级。禁止序列化与克隆密钥对象，常规调试输出脱敏，敏感入参使用 PHP 的 SensitiveParameter 属性。这里不承诺 PHP 进程中不存在任何短暂明文副本，也不能阻止拥有进程权限的调试器读取内存。

算法与附加认证数据语义依据：[PHP 加密接口](https://www.php.net/manual/en/function.sodium-crypto-aead-xchacha20poly1305-ietf-encrypt.php)、[PHP 解密接口](https://www.php.net/manual/en/function.sodium-crypto-aead-xchacha20poly1305-ietf-decrypt.php)。使用标准库，不自行设计密码算法。

- Linux PHP 独立进程 **523 项断言通过**：中文/多行往返、每个封装字节篡改、跨用户和跨请求、错误密钥与 key ID、随机 nonce、非法/超大/旧明文、对象序列化及调试输出边界。
- 测试只使用运行时随机密钥及合成联系方式，不使用真实联系信息或生产密钥；没有邮件发送。
- 执行边界为 PrivateNetwork、NoNewPrivileges、ProtectSystem、ProtectHome，以及禁止访问生产 Webroot、配置、MySQL 数据和 socket 的 systemd 沙箱。仅传入 `/tmp` 下的两个测试源码文件。
- PHP 组件语法及断言接入已有源码门禁；本机没有 PHP 时不会伪称本机执行通过，PHP 证据来自上述隔离进程。
- 本轮源码门禁通过；条件跳过的 PHP/Composer 与 Linux flock 不计入本机执行证据。
