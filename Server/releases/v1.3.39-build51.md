# Build 51：管理员海报预览与实际开屏统一

App `1.3.39 (51)`，2026-09-05。包含 Build 50 的相册缩放/拖动修正。

## 问题与修正

- App 内“内容管理 → 开屏海报”仍使用独立的固定 9:16、完整源图、紧凑字体和旧渐变；实际开屏已改为当前窗口的自适应铺放、安全区和字体，两处实现发生分歧。
- 抽出同一个 `LaunchPosterCanvas`，实际开屏与管理员预览共用。预览按当前窗口等比缩小，旋转后相应调整，不另行维护字体或图片裁切规则；仅按预览显示尺寸解码，避免小预览产生整窗纹理开销。
- 实际开屏保留原来的渐显、文案、字体、跳过、辅助功能阅读时间和投放计时；管理员预览没有自动关闭计时器，缩小的跳过控件不可操作且不进入辅助功能列表。预览范围使用实际可见矩形，避免图片未裁切的辅助功能边界侵入其他控件。
- 新增海报不再填入 `SEASONAL POSTER / 镜头之内，自有叙事。`，改为与客户端默认开屏共用“东方美学 / 易姝 / 很高兴，在这里遇见你。”。只影响新草稿，不覆盖已有海报、管理员手动文案、日期或时长。
- 明确预览展示的是未发布草稿；图片替换后仍需“保存并发布全部修改”。不自动发布、不改云端内容、不部署服务器、不添加图片磁盘缓存。

## 验证与发布

当前为准备发行的候选，尚未上传或确认 TestFlight 可测试。回归包括新增默认草稿与比例单元测试、iPhone/iPad 横竖屏及明暗配置下的预览范围、草稿实时更新、不自动消失、不暴露跳过操作，以及实际开屏全屏与跳过回归。

中间候选的测试暴露了未裁切图片的辅助功能范围、测试按钮的可点击性与缩略跳过控件的问题；失败结果不作为通过证据，修正后重新运行。独立 Debug 预览夹具只显示测试海报和本地编辑按钮，不建立管理员会话或调用发布 API，Release 必须排除其启动参数。发行与测试结果确认后再更新本记录。
