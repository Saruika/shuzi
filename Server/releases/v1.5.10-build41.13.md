# App Content API 1.5.10 / Build 41.13 健康监控安装器发布记录

该记录随 Git 标签 `v1.3.29-build41.13` 保存。Build 41.12 已发布 GitHub，
备用节点事务在 `COMMITTED` 后发现 `/var/log` 为 Ubuntu 24.04/rsyslog 的标准
`root:syslog 0775` 目录，旧安装器错误要求它必须 root:root 且不可组写，因而
停止。事务已写入 root-only `ROLLED_BACK`，五项备份完整性、旧 runtime 三哈希、
timer 排程及 Nginx、PHP-FPM、MySQL 均复验正常；主节点没有执行 Build 41.12。

Build 41.13 不放宽 `/var/log` 为“安全目录”，也不改变系统管理的目录或日志。
安装器完全移除日志 chmod/chown 逻辑，只升级健康 runtime。健康脚本新增从根
目录到日志父目录的 root-only 信任链：任一父目录不是 root:root、可由非 root
写入、是链接或非规范路径时，在查询日志是否存在、读取 mtime 或内容之前立即
返回固定 untrusted 摘要。这样 `root:syslog 0775` 下的文件、成功 marker 与
generation 都不能影响可信健康结论。即使未来迁入可信父链，日志也只通过固定
目录/文件描述符限量读取，并在读取前后复核路径、inode 与元数据；轮换竞态会
安全降级为 untrusted，而不会读取替换文件或造成健康任务崩溃。

两个节点会有意保持 `degraded`，`critical_reasons` 必须为空，业务服务与路由
必须全部正常。备用节点只接受以下六项有序原因：

```text
snapshot_last_success_untrusted_or_stale
standby_failover_state_unhealthy_or_stale
standby_failover_timer_disabled
standby_sync_generation_missing_or_invalid
sync_last_success_untrusted_or_stale
sync_log_generation_missing_or_invalid
```

主节点只接受以下五项有序原因：

```text
authority_sync_generation_missing_or_invalid
snapshot_last_success_untrusted_or_stale
sync_last_success_untrusted_or_stale
sync_log_generation_missing_or_invalid
sync_timer_missing_or_disabled
```

任意缺项、多项、顺序或状态漂移都触发回滚。当前高风险同步与自动故障切换
继续保持禁用。本版本也不会改写它们；后续应把仍由 root shell 重定向写入
共享 `/var/log` 的快照/同步证据迁到 root:root 0700 的专用 `/var/lib` 父链。

## 生产启动门禁

不得直接执行仓库副本。先把标签中的安装器原子安装到
`/run/deploy-shuzijun-health-build41.13`，设为 `root:root 0700`、regular、
non-link、nlink=1；三个 runtime 候选分别放入仅含这三项的
`/run/shuzijun-health-build41.13-backup` 和
`/run/shuzijun-health-build41.13-primary`。备用节点必须先成功。

```bash
sudo /usr/bin/env -i PATH=/usr/sbin:/usr/bin:/sbin:/bin LC_ALL=C LANG=C /bin/bash --noprofile --norc -c '
set -Eeuo pipefail
DEPLOYER=/run/deploy-shuzijun-health-build41.13
DEPLOYER_SHA256=041b7f57f8136655e7829950327e479b8879b78842811107bb00f35c5f855218
[[ ! -L "$DEPLOYER" && -f "$DEPLOYER" ]]
[[ "$(/usr/bin/realpath -e -- "$DEPLOYER")" == "$DEPLOYER" ]]
[[ "$(/usr/bin/stat -c "%F:%u:%g:%a:%h" -- "$DEPLOYER")" == "regular file:0:0:700:1" ]]
[[ "$(/usr/bin/sha256sum -- "$DEPLOYER")" == "$DEPLOYER_SHA256  $DEPLOYER" ]]
exec /bin/bash --noprofile --norc "$DEPLOYER" backup standby
'
```

备用节点完整验收通过后，主节点仅将最后一行替换为：

```bash
exec /bin/bash --noprofile --norc "$DEPLOYER" primary authority
```

该事务不运行同步、快照或故障切换，不修改 DNS、CDN、Nginx、PHP-FPM、
MySQL、WordPress 内容、媒体或 `/var/log`。有效 `DONE` 是提交点；事务前门禁
或隔离失败必须 fail-closed，不得误报成功。
