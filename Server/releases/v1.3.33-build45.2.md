该记录用于 Git 标签 `v1.3.33-build45.2`。iOS 仍为 `1.3.33 (45)`，App Content API
仍为已部署并验证的 `1.5.12.1`。备用节点首次安装 Worker 时，Bash 在一条组合 `local`
声明内先展开尚未赋值的 `target`，被 `set -u` 正确拦截；部署器随后自动回滚了五个候选
文件，上海 authority 未执行安装，且没有通知被发送。

PHP-FPM 环境片段及 APNs 安全配置均未改变。

全部通过后，才能开始 TestFlight 真机定向推送验收。
