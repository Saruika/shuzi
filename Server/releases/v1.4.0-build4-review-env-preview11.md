## 修复

私有代理原本会把所有客户端按 127.0.0.1 计数，且位于 rewrite 前位置的限流不能可靠覆盖最终
FastCGI location。现在公共边缘覆盖 `X-Yishu-Client-IP`，只有回环来源被内部 realip 信任，
限流放到实际 PHP 执行位置并使用 429。没有放宽应用的注册频率、审批或管理员鉴权。
