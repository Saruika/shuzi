# Hi，梳子 1.3.30 / Build 42.9 CI 供应链发布记录

该记录随 Git 标签 `v1.3.30-build42.9` 保存。本版是纯 CI、依赖锁定和构建来源
维护，不修改 App 页面、图片、播放器、用户数据、DNS、CDN 或生产服务器。

- Python 生产直接依赖精确锁定 3 个，完整传递图锁定 33 个；CI 质量工具
  直接依赖精确锁定 4 个，完整传递图锁定 38 个。每个可接受的分发包都带
  SHA-256，CI 用 `--require-hashes` 安装。
- SAST 由 Bandit 覆盖生产 Python 服务与运维脚本，中/高严重性且中/高置信度的
  发现会阻断构建；Swift 另执行 Xcode compiler analyze 和 warnings-as-errors。
- SCA 在每次 main push 与 Pull Request 同时执行两份 Python 锁的 `pip-audit` 和
  Composer 锁的 `composer audit`，不依赖私有仓库另行付费的 GitHub Code Security。
- 每次构建生成 CycloneDX 1.6 与 SPDX 2.3 SBOM，并连同 runner provenance 保留
  30 天。CycloneDX 使用官方 1.6 schema 验证；SPDX 使用固定提交及 SHA-256
  的官方 2.3 schema 验证，并额外执行关系语义合同。
- `macos-26` 明确为 GitHub-hosted rolling runner，并记录官方 runner-images 来源、
  ARM64 镜像定义和每次 ImageVersion。每次运行失败关闭核对 macOS 26 / ARM64、
  Xcode 26.6 (`17F113`) 与 Python 3.12.14，同时记录 ImageVersion、工具真实路径、
  版本、二进制 SHA-256 和 15 项构建材料哈希。PHP 固定在受审的 8.3
  小版本线，并记录每次实际补丁版本、路径和二进制哈希；Composer 2.9.8
  使用精确版本选择器并失败关闭核对。
- 5 个 GitHub Actions 调用全部锁定到 40 位提交，workflow 只授予
  `contents: read`。
