# 上架验收第四轮：合作邮件失败时不自动复制私人信息

2026-09-13；基线 2e8b3cd。仅本地修复，不上传、推送、改审核信息或降低正式截图保护。

## 问题与修复

CollaborationInquiryView.sendEmail 在 URL 构造失败或系统没有可用邮件处理程序时，会自动把联系人、联系方式、项目及预算说明写入系统剪贴板。用户点击的是发送邮件，不是复制；现有隐私说明将复制描述为用户主动选择，此处行为不一致。

现在两个失败分支仅展示提示，不写剪贴板。提示明确说明“尚未发送，也未自动复制”，提供主动“复制邀约内容”按钮；页面原有复制按钮保留。只有这两个明确复制操作调用 copyInquiry。取消提示后保留表单，不打开第三方网页，不发送或保存到服务器。

没有改动正常 mailto 目标、邮件正文、合作服务器提交开关或主页面布局；没有启用自动邮件/管理员推送。现有发行 Build 6 的行为不因本地修改而改变。
