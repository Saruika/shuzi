# Build 48 后续源码修正：Apple 登录、开屏与粗略位置

2026-09-05；这是源码小版本，不是已上传的新 TestFlight 构建。当前可安装版本仍是 1.3.36 (48)。

## 修改

- Apple 系统授权暂时使页面 inactive 时不再取消请求；真正进入后台时取消并清理注册草稿。返回前台不再仅因系统弹窗关闭而清空已填写资料。
- 先判断授权控制器是否仍是当前请求，再校验回调；已取消/被替换的旧回调不再结束新请求，重复回调只完成一次。
- 保持 nonce/state 校验、服务端验证、抖音 ID 必填和管理员审批，不增加账号自动合并或审批旁路。
- 开屏移除自动缩放和东方美学前的装饰横线，保留淡入、跳过、阅读时间和辅助功能适配。客户端备用欢迎语改为“很高兴，在这里遇见你。”；云端管理配置尚未改写，因此受管海报仍可能显示旧文案。
- 默认请求粗略位置，发送至地理编码/WeatherKit 前降低坐标精度，丢弃高度及运动信息；不改首页天气入口或归属展示位置。

- 本地新增 Apple 生命周期、开屏、天气精度源代码契约检查通过。
- 上海只读 WordPress 检查：JWT 库就绪、client ID 匹配、测试模式关闭；但 Apple 登录签名和数据密钥配置项缺失。未轮换密钥、未修改或创建生产账号。
- 尚未进行真实 Apple ID/Face ID 授权、真实授权码交换、真实 Apple 删号验收。模拟器模拟注册门禁不代表 Apple 端到端登录成功。
