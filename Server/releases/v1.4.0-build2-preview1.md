# 1.4.0 (2) — 每周换图的首页画廊候选

日期：2026-09-06（UTC+8）。这是源码候选版本，不是 TestFlight 发布：当前手机测试版仍为 1.4.0 (1)，没有上传、过期构建或部署服务器。本轮按用户要求先细化视觉与交互，不急于发安装包。

## 改动范围

- 首页照片与文案、天气分区；删除照片上方的说明遮罩和主题色渐变。所有图片保持原始比例与颜色，不依赖某张照片的明暗或人物站位。
- 手机/iPad 竖屏采用上下布局，足够宽的横屏采用左右分栏。文字区域在照片之外，大字号可滚动读完说明；查看作品和页码保留独立操作空间。
- 版式只随实际窗口与字号变化，不随每周照片比例或加载完成后的高度测量变化；使用简洁的数字/细线页码。
- 每周列表调整后尽量保留当前照片；移除旧 URL 后，迟到回调不能重新写入。离开首页或进入后台后，迟到图片不能恢复已清空的页面状态。
- 图片预热和显示使用同一容器目标尺寸；仍采用有界内存缓存和原生分页，保留双向滑动、触摸暂停、松手后完整停留及图片就绪检查。
- 不更换原照片与首页文案，不改相册、关于页、影视播放器、后台内容或账号权限，不增加照片磁盘缓存或打包照片。

## 参考与依赖

比较了 Immich、IceCubesApp、Nuke、JXPhotoBrowser 等近期有维护的开源项目，参考照片优先、原生自适应、数据与展示解耦。没有复制上游源码或引入新依赖。完整 Star、活动时间、许可和选型取舍见 [首页设计说明](../../DESIGN_HOME.md)。安装包不设人为增大目标；以精致、可维护且连续的体验为准。
