# 显式服务环境入口与持续演示标识

候选版本记录：`v1.4.0-build4-review-env-preview24`，2026-09-07（UTC+8）。

## 变更

- 登录门禁页与「关于 → 设置」提供同一个服务环境选择页，正式/演示均对用户可见，
  不按 Apple 审核身份、身份码或远端参数自动切换，不增加用户名登录例外。
- 切换须确认退出当前账号和放弃未保存编辑。已有协调器先清理旧会话、推送上下文、
  导航及内存图片，再建立独立服务；只有完成切换才保存本机选择。无效偏好回到正式环境。
- 演示环境在根界面和独立受保护全屏页面持续标识；正式环境不增加横幅。
  Test1/Test2 仍需正常 HS/密码登录；切换环境不能授予访问权限或管理员权限。
- 未改变免费、抖音必填、审批规则、照片构图、播放器及原有业务内容。
- 严格 Debug 构建发现旧首页测试标识对几何类型使用了已弃用的本地化插值；
  改用 `Text(verbatim:)` 表达测试几何字符串，不改变正式首页文案或布局。
