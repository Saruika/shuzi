# 管理员内容范围与照片-only 编辑

版本记录：`v1.4.0-build4-review-env-preview25`，2026-09-07（UTC+8）。
服务端候选 `1.5.13.10`，目前未部署。

## 根因与边界

审核实例在正常 REST 查询语义下，真实配置为 2 本相册、分别 5/3 张完整图片，showreel 为空。
旧 App 将 `showreel != nil` 当作管理员完整内容证据，因此合法照片-only 配置也无法进入编辑。
直接在非 REST CLI 中调用会受到网站隐藏相册查询钩子影响返回 0 本，不能以此断言数据丢失；
已经重新按 REST 查询语义只读核查上述实际数量，没有新增视频、修改账号或作品。

- 后台内容清单新增 `contentAudience`：仅内部已鉴权的 admin 路径返回 administrator，
  普通、公开、付费兼容或完整相册权限均返回 viewer，不通过用户请求参数选择。
- App 接受明确 administrator 且所有相册完整的照片-only 内容；viewer 明确拒绝编辑。
  仍须有有效管理员会话和完整内容加载状态，不能把响应字段用作登录或角色授权。
- 旧服务器没有该字段时保留原严格逻辑，等待两节点升级；明确 viewer 不得降级走旧逻辑。
  未知/错误类型的字段无法解码，不接受任意字符串。
- 不改变截图保护、免费/抖音必填/审批规则、演员页面内容、视频播放器或服务器合作开关。
