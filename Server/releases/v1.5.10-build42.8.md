# App Content API 1.5.10 / Build 42.8 模块化发布记录

该记录随 Git 标签 `v1.3.30-build42.8` 保存。本版不改变 API 路由、
数据结构、页面文案、管理权限或合作邀约熔断状态，只将原来 8,125 行的
`shuzijun-app-content.php` 拆分为 13 行入口、核心类和四个按职责划分的
trait。拆分后的五个实现模块按原顺序重组时，与拆分前类体逐字节一致。

发布器与回滚链现在把入口和五个模块作为一个不可分割的清单化发布
单元：候选包只允许已审核的 1.5.8 bridge 或本次目标清单；已上线的
Build 41 清单 `76f159…` 只能作为受信迁移源及回滚目标，不能被重新当作
新候选包发布。全部模块 PHP 直连 URL 也纳入 Nginx 404 验收。

独立 PHP 8.3.6 隔离验证曾发现并修复一处拆分路径回归：Apple JWT 加载器
现在从 trait 的模块目录精确回到 Composer `vendor/autoload.php`，不会指向
不存在的嵌套 `vendor` 目录。
