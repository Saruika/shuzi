## 修复

- 代码核对发现独立管理员账号登录只校验了响应可解析，而绑定用户登录还要求
  `authenticated == true`、`role == yishu_content_manager` 和非空显示名称。
- 两条路径改为共享 `isVerifiedContentManager`，异常成功响应不能解锁管理界面。
  失败时清空管理身份和能力，不保留可供后续管理请求使用的旧认证；正确响应可重新登录。
- 这是客户端会话状态一致性修复，不表示已发现生产服务器越权；服务器每次请求的权限校验不变。
- 没有改动 App 页面、播放器、全屏布局、用户审批条件或服务端。仍免费、抖音 ID 必填、审批后访问。
- 新增管理员绑定使用说明，纠正 README 只描述 WordPress Application Password 的旧表格。
