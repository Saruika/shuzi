# Hi，梳子 1.3.33 / Build 45.8 推送 Worker 降权启动热修复

该记录用于 Git 标签 `v1.3.33-build45.8`。生产同构诊断确认，systemd 的
`PrivateDevices=true` 会从 Worker 启动进程的 effective/permitted 集合中移除
`CAP_SETUID`；因此 Build 45.7 虽能完成 immutable 检查，随后调用 `setresuid` 仍以
`EPERM` 退出。

本热修保留 `PrivateDevices`，并只把 `CAP_SETUID` 加入启动进程的 ambient 集合，使固定、
受哈希约束的 Worker 能完成一次 `www-data` 降权。Worker 的 `setpriv` 命令同时清空补充组、
inheritable 与 ambient capabilities，并启用 `NoNewPrivileges`。完整生产同构沙箱已用空
Outbox 验证 WP-CLI sweep 返回 0；没有通知被发送。
