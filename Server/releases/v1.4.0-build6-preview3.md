# 红果链接防失效与关于页联动候选

2026-09-08；客户端仍为 1.4.0 Build 5，服务端候选 1.5.13.14。

## 功能

- 影视代表短剧：点击红果链接时显示轻量进度，检查通过才打开外部页面。
  HTTP 200 正文为 404、HTTP 404/410 提示暂时失效；限流、超时、验证码、未知页面结构
  提示无法确认，不误报永久失效。离开页面/内容变更不再跳出旧链接，防止重复点击。
- 关于页：优先选择后台短剧中唯一的共同红果入口（至少两部共用），不是静态旧短链；
  检查确认易姝演员主页后才跳转。多个不同共同入口或只有独立剧集链接时使用新版内置主页，
  不任意选择单部剧作为演员主页。小红书、抖音和邮件链接不变。
- 管理员「影视履历 → 统一更换红果入口」检查新演员主页，并仅批量替换完全匹配的旧链接。
  不覆盖其他剧的专属链接，保留标题/图片/顺序；先改草稿，明确点击保存发布才写入后台。
  检查期间内容刷新、登录状态或草稿变化则放弃替换。
- 链接检查会话 ephemeral，无磁盘缓存/cookie/凭据；限定 HTTPS 红果域名、最多五次跳转，
  8 秒请求/12 秒资源超时、512 KiB 正文上限，不请求页面图片、脚本或视频。
- PHP 初始化默认红果链接已更新，发布完整性摘要同步更新。线上先前已修复的配置不变。
