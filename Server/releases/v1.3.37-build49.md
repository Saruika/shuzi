# Build 49：Apple 授权生命周期与开屏修正

App `1.3.37 (49)`，2026-09-05。

## 包含的修正

包含 [v1.3.36-build48.1](v1.3.36-build48.1.md) 的源码修正：

- Apple 授权期间暂时 inactive 不再取消登录；旧回调不能清理新请求。
- 开屏取消缩放和东方美学前的装饰横线；保留淡入、跳过和辅助功能阅读时间。
- 客户端备用欢迎文案改为“很高兴，在这里遇见你。”；受管云端海报文案本次未改写。
- 默认粗略定位，坐标降精度后再交给地理编码和 WeatherKit。
- 保持抖音 ID 必填及审批；不修改照片、播放器、截图兼容层或服务器凭据。

## 验证

上述源码已有 166 项 iPhone 单元测试、Apple 首次申请门禁 UI、8 项 iPad 横竖屏/明暗外观开屏与关于页回归，以及隔离源码门禁通过。此次仅增加发布版本号；归档、签名和 Apple 处理结果待补记。
