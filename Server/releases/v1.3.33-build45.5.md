# Hi，梳子 1.3.33 / Build 45.5 推送 Worker systemd 热修复

该记录用于 Git 标签 `v1.3.33-build45.5`。生产同构诊断 unit 进一步确认，systemd 的
`RestrictSUIDSGID=true` 会阻断本 Worker 有意执行的 `setresuid` 降权，因此即使不再修改
bounding set，Build 45.4 仍在切换到 `www-data` 时退出。上海定时器已暂停，没有通知被
发送。

本热修移除该项 syscall 限制；`NoNewPrivileges=true`、仅含 `CAP_SETUID/CAP_SETGID` 的
systemd bounding set、空 ambient capability、只读系统路径及其余沙箱策略全部保留。
降权后的命令仍清空补充组和 inheritable/ambient capability，无法通过 setuid 文件或文件
capability 重新获得权限。相同参数的临时 systemd unit 已验证 `www-data` 可读取 immutable
属性，最终仍以真实 oneshot 成功为发布门禁。
