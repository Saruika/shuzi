# Hi，梳子 1.3.30 / Build 42.5 腾讯云 TAT 兼容修复

Build 42.5 取代 Build 42.4 的上海节点部署器。Build 42.4 在上海节点
将 root crontab 中不存在 `stargate` 文字误判为腾讯云代理缺失，在任何
监控资产或服务变更前安全拒绝，并验证完成回滚。上海节点实际由
已激活的 `tat_agent.service` 提供腾讯云自动化通道，不需要额外 cron 行。

本版修复：

- 删除对 root crontab 中 `stargate` 文字的历史性假设，不会伪造或添加云代理定时任务。
- 迁移前按完整 SHA-256 验证 root crontab 原始字节；迁移后按完整
  SHA-256 验证仅移除旧快照行后的预期字节。
- 运行期复验继续比对完整 crontab 状态和哈希，比只比对一类关键字行更严格。
- 回滚仍逐字节恢复并验证原 crontab；快照产生器仍强制全机唯一。
- 固定路径、stage、备份名和 release ID 升级为 `build42.5`。

Build 42.4 失败后已复验上海健康 timer 仍为 enabled/active，原监控文件哈希
不变，旧快照 cron 仍且仅有一份，快照锁和发布锁均空闲。

```text
HEALTH_DEPLOYER=d8b32b19a02c284b3f3fa6cc65689d3aa2131e1dacb95466e9826e685b68c6f9
HEALTH_DEPLOYER_TEST=6a6e4f88cc0cf15975e242957173e19f004e991e45363b584f700979cadaf056
SECURITY_CHECK=ac11fb16823dbce7f94a888e26d5faebaf84ff392df3f7c5fdeadf18d49bbee9
RECEIVER=0a28c89ef1ac427f6ac72e5268cb5aa0ed28169493aab64d05dd687a40e67e03
SENDER=a4e05f87426689673d5b741a88efcd6c8e35f856ab57f5b3ba78f56a004b4356
SYNC_DEPLOYER=20a3f4deefcbdb68c7697b2f4d1f75a4e4370a1fba2940a3435acb1c2c32f73c
```

本修复不修改 DNS、CDN 主源、故障转移或 generation，不包含 SSH/签名私钥、
云 API 凭据、密码、手机号或会话令牌。
