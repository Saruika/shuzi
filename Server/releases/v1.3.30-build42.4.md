# Hi，梳子 1.3.30 / Build 42.4 文件类型门禁修复

Build 42.4 取代 Build 42.3 作为生产候选。42.3 在新加坡的最早期预检中
以退出码 1 失败关闭，未进入备份或服务变更阶段。root-only 空环境追踪
定位到快照锁的文件类型文字断言。

GNU `stat -c %F` 对合法空普通文件返回 `regular empty file`，发布器却
硬编码比较 `regular file`。`/run/tencent-snapshot.lock` 正常情况下就是空文件，
因此被误拒绝。这类文字还受 coreutils 版本与 locale 影响，不适合安全合同。

本版修复：

- 所有普通文件、目录和 symlink 类型仍由 `-f` / `-d` / `-L`、禁止跟随、
  canonical path 及打开后 inode 合同验证。
- `stat` 只回读 UID、GID、数字权限和链接数，不再解析 `%F` 自然语言文字。
- 同时覆盖快照锁、安装锁目录、stage/目标文件、status、timer wants
  symlink、私有日志和可选 cron 资产。
- 合同测试新增全局禁止 `stat -c %F`，防止后续回归。
- 固定路径、stage、备份名和 release ID 升级为 `build42.4`。

42.3 追踪文件使用空环境且未读取凭据，已立即删除。追踪后复验健康
timer 仍 enabled/active，旧监控三个文件哈希未变，快照锁与发布锁都空闲，
未生成 Build 42.3 事务备份。
