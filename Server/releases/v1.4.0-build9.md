## 问题与证据

- 用户反馈 Build 8 重装后，在“正在核对完整内容／重新载入完整内容”仍提示服务器返回无法识别的数据。
- 经批准的临时技术管理员、仅有内容管理权限的临时粉丝账号，分别在 iOS 27 模拟器 Debug 构建完成真实生产 HTTPS 登录、绑定管理会话与完整内容读取。临时凭据已撤销，临时用户及其元数据/专属任务已删除；未操作真实用户权限、未发送邮件或通知、未修改作品。
- 同一份凭据无关的生产清单（37,541 bytes，SHA256 `7bf410e1bdf3b85982ac6c7c9ac4f07c7028be0905d4482235f426ea270a1299`）在 Debug 校验成功，Release 稳定在内容策略拒绝。地址校验成功；失败集中于海报和短剧 ID。
- 独立纯 Swift 合成复现同样显示优化相关误判：在原 `isValidText` 加字符集方法引用的组合中，合法 ASCII ID 被拒绝，部分非 ASCII ID 被接受。仅改变编译优化级别即可触发，不涉及网络、账号或照片。工具链为 Apple Swift 6.4 / Xcode iOS 27 SDK；未声称上游已确认编译器缺陷。

## 变更范围

- `ContentManifestPolicy` 改用明确的 UTF-8 字节白名单 `[a-z0-9_-]`，继续要求非空、最多 80 字符并拒绝控制字符；不放宽原规则。
- 管理内容加载固定诊断码 AC01–AC06，区分响应大小、来源、格式、解码、内容策略和完整性。没有输出服务端正文、媒体地址、账号或凭据。
- 保留 401/403 锁定、环境隔离、TLS、禁止重定向、完整清单才能编辑、图片仅内存与截图保护。
- 补充 Debug / Release 可运行的合成标识符回归、管理加载及权限回归，修正测试对 Debug-only 夹具/计数器的无条件引用；不将测试专用夹具加入正式包。
- 不含排行榜、服务器部署、作品变更、真实账号调整或旧 TestFlight 构建过期操作。
