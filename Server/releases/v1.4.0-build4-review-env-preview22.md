## 范围

新增 `LiveReviewAdministratorTests/testNativeAccountApprovalBindingRevocationAndDeletion`：
直接使用 App 的 `FanAccountStore`、`AdminSessionStore` 和真实 HTTPS 传输，
不是注入假响应，也没有通过 DEBUG 门禁跳过登录后的资格检查。

1. 抖音 ID 留空时原生服务拒绝注册；随后注册本次唯一标记的合成用户。
2. 新用户保持待审批且无管理员身份；管理服务审批后刷新为普通已批准用户。
3. 通过真实管理接口绑定管理员，原生粉丝会话刷新后能建立绑定式管理员会话，
   不是另存独立管理员密码。
4. 撤销管理员后，**不先刷新粉丝本地资料**，旧管理会话下一次请求立即遭拒并锁定。
   再刷新后，仍保留普通用户审批状态，但无管理员身份。
5. 从原生用户服务自行删号；随后使用同一身份码和密码登录，必须明确得到凭据无效，
   而不是仅凭“未登录”把服务器或网络错误当作通过。
