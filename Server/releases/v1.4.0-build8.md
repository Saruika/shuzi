# 1.4.0 (8) 内嵌小游戏

## 交付范围

在现有 Hi，梳子 App 的“关于 → 小游戏”内嵌《宦海浮沉录》，不是独立 App，也不是远程网页跳转。完整迁移 6 种出身、108 题、432 个选项和 28 个结局定义，保留原始数值与结算顺序。来源、用户授权确认、测试基线与验收边界见 [内嵌游戏记录](../../Documentation/embedded-game-migration.md)。

- 游戏资源随安装包提供，离线运行；仅本局内存保留进度。
- 不接入 B 站登录、排行榜、上传、关注或海报保存，不读取 App 账号信息。
- 适配 iPhone/iPad 横竖屏，防止重复选择和旧计时回调污染新的一局。
- 原生关闭确认；取消保留本局，确认后返回“关于”。
- 继续使用既有截图保护容器、账号审批和 App 主题；不改变其他页面内容或服务器配置。

## 已保存的测试说明

### 简体中文

新增离线小游戏《宦海浮沉录》，请从“关于 → 小游戏”进入。包含六种出身、完整 108 题和不同结局。请重点测试角色选择、连续答题、iPhone/iPad 横竖屏、切换到后台后返回，以及关闭确认。游戏使用匿名身份，进度仅保留本局，关闭或重新载入后不会恢复；不接入 B 站账号或排行榜。原有相册、账号和通知功能保持不变。

### English

Adds the offline game “宦海浮沉录” inside the existing app. Open About → Mini Game to play six starting backgrounds and the full 108-question experience with multiple endings. Please test choices, continuous play, portrait/landscape layouts on iPhone and iPad, returning from the background, and exit confirmation. Play is anonymous and progress lasts for the current session only; closing or reloading starts over. No Bilibili account or leaderboard is connected. Existing gallery, account, and notification features are unchanged.
