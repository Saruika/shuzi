# App 内分配管理员身份

日期：2026-09-06（Asia/Shanghai）

候选标签：`v1.4.0-build2-preflight18`；插件版本：1.5.13.7。
基线：`c4efdd5e5f4b9165fa16cce736013fb40732afb0` / preflight17。

## 变更

- 管理会话返回 `canManageFanAdministrators`，仅完整 App 管理员且位于主写节点时为真。
  旧服务器省略时客户端默认关闭分配控件，身份提示本身不替代服务端鉴权。
- 增加鉴权后的 `GET /wp-json/shuzijun/v1/app-admin/fans/{uuid}` 精确刷新接口。
  从 URL 取目标，拒绝重复身份和无权限请求，不通过模糊搜索选择账号。
- 用户详情新增管理员身份区域。授予/撤销前重新读取用户，再明确展示目标与权限范围并要求确认。
  保留原有审批、免费政策、普通用户权限；不授予 WordPress 整站权限。
- 客户端请求只含目标状态、已知状态和修订号，响应必须匹配同一用户、目标状态和预期修订。
  缺少元数据、未审批或资料未完成时不能授予；暂停用户仍允许撤销管理身份。
- 409 冲突、超时或不确定返回后只刷新状态，绝不自动重试角色变更。
  自我修改在客户端阻止，服务端继续独立拒绝。退出管理、离开页面或退到后台时丢弃待确认动作。
- UI 测试使用 Debug 专属内存传输，不接触线上账号、凭据或媒体；Release 不包含该测试页面。
  未改动首页、相册、播放器及 About 的展示内容。
