# 消息详情返回与再次打开修复

版本记录：`v1.4.0-build2-preflight6`，2026-09-06。仅修改 App 消息箱导航与回归测试，不改页面设计、播放器、截图兼容层或生产服务器。本记录不代表已上传 TestFlight。

## 原因和修复

消息详情返回时，SwiftUI 可重新启动消息箱的刷新 task，旧实现会再次消费同一条初始推送并重新打开详情。原布尔导航绑定同时从可选消息 ID 推导展示状态，返回和手动再次打开之间可能不一致。

改为每个当前账号上下文只自动消费一次初始推送，并在刷新后校验任务取消和账号上下文；切换账号时清除导航状态。详情使用公开的 `navigationDestination(item:)` 直接绑定消息 ID。用户仍可主动再次打开消息，详情原有清理和权限检查保留。
