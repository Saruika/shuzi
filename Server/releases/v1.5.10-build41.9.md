该记录随 Git 标签 `v1.3.29-build41.9` 保存。Build 41.8 在备用节点进入
事务前安全拒绝：Ubuntu 对空普通文件的 `stat %F` 描述为
`regular empty file`，而候选安装器只接受 `regular file`。当时尚未创建
事务备份，也未停止 timer、替换 runtime 或触发回滚。

Build 41.9 保留 Build 41.8 的 typed D-Bus ExecStartEx、root-only 事务、固定
角色和严格终态合同，仅将空锁文件的类型验证改为 `-f`、非链接、canonical
path 及数值 owner/group/mode/nlink，不再依赖本地化的 `%F` 文案。

## 生产启动门禁

不得直接执行仓库副本。先把标签中的安装器原子安装到
`/run/deploy-shuzijun-health-build41.9`，设为 `root:root 0700`、regular、
non-link、nlink=1；三个 runtime 候选分别放入仅含这三项的
`/run/shuzijun-health-build41.9-backup` 和
`/run/shuzijun-health-build41.9-primary`。备用节点必须先成功。

```bash
sudo /usr/bin/env -i PATH=/usr/sbin:/usr/bin:/sbin:/bin LC_ALL=C LANG=C /bin/bash --noprofile --norc -c '
set -Eeuo pipefail
DEPLOYER=/run/deploy-shuzijun-health-build41.9
DEPLOYER_SHA256=fd402b62bd5eaab96f3689cf503d1602fc11e11548be604876b563b8e1b5a857
[[ ! -L "$DEPLOYER" && -f "$DEPLOYER" ]]
[[ "$(/usr/bin/realpath -e -- "$DEPLOYER")" == "$DEPLOYER" ]]
[[ "$(/usr/bin/stat -c "%F:%u:%g:%a:%h" -- "$DEPLOYER")" == "regular file:0:0:700:1" ]]
[[ "$(/usr/bin/sha256sum -- "$DEPLOYER")" == "$DEPLOYER_SHA256  $DEPLOYER" ]]
exec /bin/bash --noprofile --norc "$DEPLOYER" backup standby
'
```

备用节点完整验收通过后，主节点仅将最后一行替换为：

```bash
exec /bin/bash --noprofile --norc "$DEPLOYER" primary authority
```

## 验收与边界

- 两节点 runtime 及 loaded unit 必须命中固定哈希、typed path/argv/flags、
  root 空环境执行上下文，timer 必须 enabled/active 且下次触发稳定。
- authority 必须只报告 `authority_sync_generation_missing_or_invalid`、
  `sync_log_generation_missing_or_invalid`、`sync_timer_missing_or_disabled`。
- standby 必须只报告 `standby_failover_state_unhealthy_or_stale`、
  `standby_failover_timer_disabled`、`standby_sync_generation_missing_or_invalid`、
  `sync_log_generation_missing_or_invalid`。
- 两节点 `critical_reasons=[]`，核心服务 active，固定路由全部 `ok=true`，
  systemd 允许健康脚本以 degraded/exit 2 正常完成。

该事务不运行同步或故障切换，不修改 DNS、CDN、Nginx、PHP-FPM、
MySQL、WordPress 内容或媒体。失败只能在验证隔离后回滚固定旧字节；
有效 `DONE` 是不可反向回滚的提交点。
