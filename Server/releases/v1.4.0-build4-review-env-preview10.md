## 实际验证

- 主节点独立核心原目录和复制后均通过 WordPress 7.1 / en_US 官方校验。
- 私有实例的 23 项真实检查连续两次通过；普通用户不能自行审批或访问管理，授予和撤销立即生效。
- 14 项本地引导边界/就绪测试通过；完整 `Scripts/security-check.sh` 通过。Mac 上 7 项 Linux 专用锁测试跳过，本地 PHP/Composer 分支未运行；这不是完整 iOS/云端 CI 或全新最终脚本再次安装的验收。
- MySQL 仅审核库权限，没有全局数据权限或 GRANT OPTION；只可列出审核库与系统元数据 schema。

- 本机 127.0.0.1:18089 listener；未新增公网 HTTP 入口、域名、证书或 App 选择器。
- 正式 nginx、PHP-FPM、MySQL、同步 timer 均 active，正式插件清单仍为下述 previous live 值。
