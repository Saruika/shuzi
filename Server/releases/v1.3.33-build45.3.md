# Hi，梳子 1.3.33 / Build 45.3 推送 Worker 权限热修复

该记录用于 Git 标签 `v1.3.33-build45.3`。iOS 与 App Content API 版本不变。首次在
上海 authority 启动 Worker 时，systemd 的最小 capability 边界使 root 进程不能读取
由 `www-data` 独占读取的 0400 密钥文件属性，Worker 以配置错误退出；定时器随后已暂停，
没有通知被发送。

本热修不扩大 systemd capability。Worker 仅在校验 immutable 属性时用 `setpriv` 降权到
文件所有者 `www-data`，同时清空补充组和全部 capability；实际 WP-CLI sweep 仍沿用相同
的无 capability 降权边界。旧 Worker 先通过已审核部署器卸载，新版本按备用节点在前、
上海 authority 在后的顺序重新安装。
