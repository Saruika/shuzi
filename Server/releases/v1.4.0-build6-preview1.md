# 相册可见性管理候选

2026-09-08（UTC+8），服务端 1.5.13.13；客户端基于 1.4.0 Build 5。

## 使用

App 管理员进入「内容管理 → 照片作品」，选择相册后切换「相册是否可见」。
开关单独即时保存，无需再点“保存并发布全部修改”。服务端确认后才更新开关；
正在保存时不可重复点击，失败保留原状态。两位管理员修改发生冲突时要求刷新。
隐藏相册在管理员选择器中标注“已隐藏”，可继续编辑照片并恢复显示。
原有相册默认可见，关闭不删除照片，不改变首页、海报、关于页等独立图片配置。

## 实现与权限

- 新增 POST `/shuzijun/v1/app-content/portfolio/{id}/visibility`，沿用管理员鉴权、
  主节点写入限制、发布锁、操作人锁和锁后重新鉴权，不开放匿名或普通用户修改。
- 严格接受 JSON 布尔 `isVisible`、`expectedIsVisible`；目标 ID 取路由。
  当前状态不一致返回 409；保存后回读确认，返回完整管理清单及 private/no-store。
- `_app_is_hidden` 缺省代表可见；仅明确字符串 `1` 隐藏。公共、已审批和旧 premium
  清单在生成照片 URL 前过滤，管理清单保留。修改图库不会重置该字段。
- 客户端分离管理员相册和用户展示相册；作品、搜索、收藏数据源不保留隐藏相册。
  全部隐藏是有效空清单，不再用旧列表替代；正在查看的相册随清单更新关闭。
  缓存摘要不写隐藏条目，未增加照片本地存储。
- 连接旧后台时保留相册编辑能力，禁用不受支持的可见性开关并显示更新说明。
