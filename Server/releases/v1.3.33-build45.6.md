# Hi，梳子 1.3.33 / Build 45.6 推送 Worker 属性校验热修复

该记录用于 Git 标签 `v1.3.33-build45.6`。Build 45.5 在上海节点完成安装后，真实
oneshot 的空队列自检发现：systemd 沙箱内以 `www-data` 运行 `lsattr` 不能读取密钥文件
的 immutable 元数据，Worker 因而以配置错误退出。推送表当时没有待发送任务，未发送
任何通知。

immutable 位属于 root 管理的部署不变量，本热修在 Worker 降权前以 root 只读检查该位；
文件仍必须位于不可写的 root 管理目录，并保持 `www-data:www-data`、`0400`、单硬链接与
immutable。实际 WordPress/APNs 投递命令仍通过 `setpriv` 切换到 `www-data`，清空补充组
和 inheritable/ambient capability，并受 `NoNewPrivileges` 与 systemd 沙箱约束。
