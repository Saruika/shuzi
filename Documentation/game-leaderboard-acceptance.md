## 功能边界

- 游戏仍内嵌在现有 App，6 种出身、108 题、432 个选项、28 个结局及原规则不变。
- 不接第三方游戏平台身份或 SDK；原生页通过现有已审批 App 会话访问排行榜。
- 未主动确认不发成绩。结局桥接只准备内存中的出身/选项，原生确认后才提交；服务器重演计分。
- 每账号一条最高成绩，同分保留先上榜者；只显示昵称与成绩摘要，系统身份码、UUID、自动账号回退名和邮箱型昵称回退为“玩家”。
- 可单独撤回成绩；App 或 WordPress 删除账号时沿用同一账号锁清理；换号、退出、会话或环境更新清空客户端榜单和待提交局，普通退出不会删除服务端最高成绩。
- 弱网 POST/DELETE 显示处理中，不自动重试写操作；服务不可用不影响离线游戏。
- App 政策、官网政策模板、隐私清单和披露清单新增与身份关联的游戏内容，仅 App 功能、非追踪。
