## 复验

在仓库根目录运行 Node 20+，无需安装第三方依赖或访问本机原型目录：

```sh
node --test Scripts/test-embedded-game-parity.mjs
```

该测试在独立 Node VM 中直接执行原版与迁移版函数，逐次比较选择后的状态；仅使用最小 DOM、虚拟计时器和阻断外部能力的 SDK 占位，不重写一套游戏规则替代源程序。

2026-09-16 本次运行：14 项通过，0 失败，0 跳过。

- 数据为108题、432个选项、28个结局。迁移版 events/endings 与原基线逐字节相同。
- 检查六种出身可见六维及隐藏廉洁/声望，保留未定义的精力/风险/家庭被忽略、每次选择覆盖廉洁/声望的原行为。
- 即时贪腐阈值为85，最终结算为80；即时结束优先顺序为贪腐、健康、民心。即时民心条件与最终条件不同，不能合并。
- 结局按原数组顺序选首个命中项；rank22的两个结局保持原次序。flags 不参与实际题目分支或结局谓词。
- 16,380组阈值边界状态；36条固定路线共3,436次选择；3,072条固定种子路线共331,776次选择，逐步比较六维、隐藏量、flags、计数、日志、段位、结局、得分和回顾顺序。
- 抽象有界状态分析未发现被前序谓词完全覆盖的结局；这不证明108题路径能到达所有结局。固定种子样本观察到13个结局，不声称28个都已验证可达。

本地原型目录的 `ORIGINAL-RULES.md` 另记录完整规则表及取证过程；该笔记不是运行本仓库测试的依赖。可复验事实与源基线均保存在本仓库。

本地匿名身份、阻断远程平台能力、重复点击防护及后台/重开计时器处理属于 App 宿主适配，昵称不在规则差分字段内；游戏数值和原结算顺序保持不变。测试不执行或验证正式账号登录、排行榜上传、关注、海报生成等原平台操作。

Node VM 不是浏览器或 iOS 设备：测试通过不等于真实布局、VoiceOver、WKWebView、截屏保护、iPhone/iPad验收或发布完成。正式 App 验证及发布仍按项目流程单独执行。
